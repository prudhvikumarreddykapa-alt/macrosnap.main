# MacroSnap 🥗

## Quick start

1. Install Python 3.12 or newer.
2. Double-click `run.bat`, or run `./run.ps1` in PowerShell.
3. On first launch, the script creates a local `.venv` and installs the packages in `requirements.txt`.
4. The app opens at `http://localhost:8501`.

The `.streamlit/secrets.toml` file contains the Gemini and Twilio credentials for this copy. Keep this ZIP private. Update that file to rotate credentials.
